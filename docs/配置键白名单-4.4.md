# 4.4 配置键白名单（overrides）

> 适用 Mod 版本：4.4
> 对应云端文件：`modConfigKeys.js`
> 全量：**180 项**

## 1. 直接替换

已生成可直接替换的数组：

`docs/modConfigKeys-180.js`

```js
module.exports = [
  "server.port",
  // ... 共 180 项
];
```

如果云端已有自己的注释/分组，不要整文件覆盖，只把数组内容替换成这 180 项即可。

## 2. 4.4 相对 4.3 的实际差异：新增 12、移除 2

云端已用差集实测确认：**不是「新增 9 + 还差 1」，而是「新增 12 + 移除 2」**。

```text
4.3 白名单 170 项
+ 新增 12 项
- 移除 2 项（整个 tts_audio_sink 段）
= 4.4 白名单 180 项
```

### 2.1 新增 12 项

| 键 | 类型 | 默认 | 说明 |
|---|---|---|---|
| `ai_extensions.webSearchAlways` | 布尔 | `false` | 每轮都搜索 |
| `ai_extensions.webSearchCustomUrl` | 字符串 | `""` | 自定义搜索接口地址，HTTPS；http 仅限本机回环 |
| `ai_extensions.webSearchCustomBody` | 字符串 | `{"query":"{query}","count":{count}}` | 支持 `{query}` / `{count}` / `{key}` |
| `ai_extensions.webSearchCustomHeaders` | 字符串 | `Authorization: Bearer {key}` | 每行一个「名称: 值」 |
| `ai_extensions.webSearchCustomResults` | 字符串 | `results` | 结果数组点号路径 |
| `ai_extensions.webSearchCustomFields` | 字符串 | `title=title,content=summary\|snippet,url=url` | 输出名=字段\|回退 |
| `gameplay_safety.allowVerityGift` | 布尔 | `true` | 潜行 + Q 送礼 |
| `gameplay_safety.allowVerityKick` | 布尔 | `true` | 潜行 + 左键踢 Verity |
| `gameplay_safety.dailyKarmaGainCap` | 整数 | `3` | 每日好感上限，`0~20`，0=不限制 |
| `plugin.enabled` | 布尔 | `true` | 插件系统总开关（4.3 漏收录） |
| `plugin.maxLoaded` | 整数 | `30` | 同时加载插件上限，`0~500` |
| `plugin.allowBlockEdit` | 布尔 | `false` | 是否允许插件编辑方块 |

### 2.2 移除 2 项

`tts_audio_sink` 整段在 4.3 起已删除，旧白名单里的两个键应移除：

```text
tts_audio_sink.*（整段 2 项）
```

### 2.3 复查命令

```js
// 在存放两个文件的目录执行
const current = require('./modConfigKeys');
const full = require('./modConfigKeys-180');
console.log('current', current.length, 'full', full.length);
console.log('missing', full.filter(key => !current.includes(key)));
console.log('extra', current.filter(key => !full.includes(key)));
```

正确结果应为 `current 180 | full 180`、`missing []`、`extra []`。

## 4. 安全例外（即使白名单有，客户端也不会应用）

下面这些键可以保留在白名单里，但 Mod 端会主动忽略：

| 键组 | 原因 |
|---|---|
| `cloud.*`（7 项） | 云端总开关/密钥/地址等安全字段，禁止云端改写 |
| `ai_extensions.webSearch*`（9 项） | 搜索服务商、密钥、自定义接口整组由本机管理，防止云端替换本地密钥或替玩家开启未配置的搜索 |

所以「180 项都在白名单里」不等于「180 项都能被云端改」；这是预期行为。
